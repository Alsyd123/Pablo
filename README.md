# Pablo

This repository is configured as an Android app project skeleton.

## Structure

- `app/` contains the Android app sources
- `build.gradle` configures the project-level Gradle settings
- `settings.gradle` includes the app module

## Local development

Open this folder in Android Studio and sync Gradle.

If you already have a project in `/workspaces/Pablo`, copy your source files into the matching Android folders here:

- Java/Kotlin code -> `app/src/main/java/...`
- XML layouts -> `app/src/main/res/layout/...`
- Strings/resources -> `app/src/main/res/values/...`
- manifest -> `app/src/main/AndroidManifest.xml`
